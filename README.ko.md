<h1 align="center">ThyTube</h1>

<p align="center"><em>thy</em> (영어 녯말, 관형ᄉᆞ): 그ᄃᆡ의.<br>
ᄂᆞᆷ의 Tube도 아니오 뎌 사ᄅᆞᆷᄃᆞᆯ의 Tube도 아니라. <strong>그ᄃᆡ의</strong> Tube니라.</p>

<p align="center"><a href="README.md">English</a> · 됴션말</p>

> 이 글월은 근ᄃᆡ 국어로 젹엇ᄂᆞ니, 아래아(ㆍ)와 ㅅ계 병셔(ㅺ ㅼ ㅽ)ᄅᆞᆯ 그릴 ᄌᆞ톄(Noto Sans CJK KR)가 이셔야 바로 뵈ᄂᆞ니라.

---

ThyTubeᄂᆞᆫ 그ᄃᆡ의 집 그믈 안헤셔 ᄡᅳᄂᆞᆫ YouTube 간직 셔버니, 제 화면도 ᄯᆞ로 ᄀᆞ초앗ᄂᆞ니라.
그ᄃᆡᄂᆞᆫ **체**(뎨목 법식, 길이, Shorts, 방송)로 ᄎᆡ널을 구독ᄒᆞ고, 그 체ᄅᆞᆯ 디나ᄂᆞᆫ 영샹은 크기가
뎡ᄒᆞᆫ 곳간에 ᄂᆞ려바다 그ᄃᆡ의 손젼화와 tablet과 computer에 내여 주ᄂᆞ니라. YouTube가 yt-dlpᄅᆞᆯ
ᄭᆡ티면 (반ᄃᆞ시 ᄭᆡ티리라) ThyTube가 이ᄅᆞᆯ ᄭᆡᄃᆞ라 두ᄃᆞ리기ᄅᆞᆯ 그치고, yt-dlpᄅᆞᆯ 고치며, 므ᄉᆞᆷ
일이 잇ᄂᆞᆫ지 그ᄃᆡ의게 ᄇᆞᆰ히 니ᄅᆞᄂᆞ니라.

권ᄒᆞᄂᆞᆫ 영샹도 업고 광고도 업고, 스ᄉᆞ로 니어 ᄌᆡᄉᆡᆼᄒᆞ야 ᄭᅳᆺ업시 ᄲᅡ져드ᄂᆞᆫ 굴도 업ᄂᆞ니라. 오직 그ᄃᆡ가
쳥ᄒᆞᆫ 영샹ᄲᅮᆫ이니, 다 그ᄃᆡ 제 디스크에 잇ᄂᆞ니라.

## ᄒᆞᄂᆞᆫ 일

- **셔고**: 간직ᄒᆞᆫ 것, 그ᄃᆡ가 보다가 그친 것, ᄎᆡ널마다 ᄀᆞᆯᄒᆡ기. ᄭᅳᆺ업ᄂᆞᆫ 두루마리ᄂᆞᆫ 업고
  "더 가져오기" 단쵸ᄲᅮᆫ이니라.
- **ᄌᆡᄉᆡᆼ긔**: 보ᄂᆞᆫ 이마다 어ᄃᆡ셔 그쳣ᄂᆞᆫ지 긔억ᄒᆞ고, 쟝을 ᄌᆞ리 막대에 뵈고, ᄌᆞ막을 제 손으로
  그리ᄂᆞ니라 (YouTube의 긔계 ᄌᆞ막은 그 더듬ᄂᆞᆫ 거ᄉᆞᆯ ᄭᆡᄭᅳᆺ이 시서 내ᄂᆞ니라). 두 번 두ᄃᆞ리면
  건너ᄯᅱ고, desktop에셔ᄂᆞᆫ 자판 지름길도 잇ᄂᆞ니라. 영샹이 ᄆᆞᄎᆞ면 ᄀᆞᆺᄐᆞᆫ ᄎᆡ널에셔 ᄃᆞᄅᆞᆫ 거ᄉᆞᆯ
  고ᄅᆞ되, 그ᄃᆡ가 ᄀᆞ장 젹게 본 거시 두 ᄇᆡ나 자조 나오ᄂᆞ니라.
- **ᄎᆞᆺ기**: 셔버의 yt-dlp로 YouTubeᄅᆞᆯ ᄎᆞᆺ고, 브틴 쥬소도 밧ᄂᆞ니라. 모든 결과에 *이 영샹
  간직ᄒᆞ기*와 *이 지은이 간직ᄒᆞ기…*가 잇ᄂᆞ니, 뒤의 거슨 체 셜뎡 창을 여러 요ᄉᆞ이 올닌 영샹 듕
  어ᄂᆞ 거시 걸닐지 바로 미리 뵈ᄂᆞ니라.
- **언약을 딕희ᄂᆞᆫ 곳간**: 뎡ᄒᆞᆫ 한도ᄅᆞᆯ 결단코 넘지 아니ᄒᆞᄂᆞ니라. ᄃᆞ시 본 일이 ᄀᆞ장 젹은 영샹이
  몬져 ᄇᆞ려지고, 새로 ᄂᆞ려바다 아직 아니 본 거슨 말믜ᄅᆞᆯ 엇고, 굿게 자븐 거슨 남고, 시방
  ᄌᆡᄉᆡᆼᄒᆞᄂᆞᆫ 거슨 ᄇᆞ리지 아니ᄒᆞᄂᆞ니라.
- **형셰**: `ok → degraded → blocked`로 옴기ᄂᆞᆫ circuit breaker와 canary 시험이 잇고, ᄆᆡ일
  yt-dlpᄅᆞᆯ 고치되 밋기 젼에 시험ᄒᆞ고 더 사오나오면 젼 판으로 도로 돌니ᄂᆞ니라.
- **보ᄂᆞᆫ 이**ᄂᆞᆫ 암호 업시 ("뉘 보ᄂᆞ뇨?"). 그ᄃᆡ의 LAN 안헤셔만 ᄡᅳᄂᆞ니, 여긔 니ᄅᆞᆫ 이ᄂᆞᆫ 다 미들
  만ᄒᆞ니라.
- **셜티ᄒᆞᆯ 수 이숌**: Progressive Web App이니, ᄃᆞᄅᆞᆫ app ᄀᆞᆺ치 그ᄃᆡ의 홈 화면에 안ᄂᆞ니라
  ([HTTPS](#https) 보라).

## 그ᄃᆡ의게 이실 것

- Linux, Python ≥ 3.13, ffmpeg와 ffprobe
- yt-dlp가 YouTube의 시험을 풀 JavaScript runtime (본ᄃᆡᄂᆞᆫ Node; `ytdlp.js_runtime` 보라)
- frontend와 영샹을 내여 주고 `/api`ᄅᆞᆯ 넘겨 줄 Apache나 ᄃᆞᄅᆞᆫ web 셔버
- yt-dlpᄂᆞᆫ Python 의존 ᄭᅮ러미가 **아니니**: `thytube update-ytdlp`가 제 venv에 ᄯᆞ로 셜티ᄒᆞ고,
  오직 ᄯᆞ로 ᄂᆞᆫ process로만 돌니ᄂᆞ니라

## 엇더케 노혓ᄂᆞ뇨

```
<origin>/                 app의 집 (ᄲᆞᄅᆞᆫ 디스크)
  app/  venv/             코드와 그 venv
  ytdlp/venv-…/ current   셜티ᄒᆞᆫ yt-dlp 판ᄃᆞᆯ; `current`ᄂᆞᆫ ᄒᆞᆫ 번에 밧고이ᄂᆞᆫ symlink
  data/thytube.sqlite3    db (WAL)
  config.toml  logs/  run/
<pool>/                   영샹 (큰 디스크); 일군만 여긔 ᄡᅳᄂᆞ니라
  media/<id[0:2]>/<id>/video.mp4, thumb.jpg, subs/<lang>.<manual|auto>.vtt
  channels/<channel id>/avatar.jpg
  .partial/               ᄂᆞ려밧ᄂᆞᆫ 듕인 것 (ᄀᆞᆺᄐᆞᆫ 파일 톄계라 ᄆᆞᄎᆞᆷ이 ᄒᆞᆫ 번의 rename이니라)
```

ᄒᆞᆫ 코드에셔 두 process가 도ᄂᆞ니, `thytube serve`(web과 API)와 `thytube worker`(YouTube에 가ᄂᆞᆫ
큰 왕ᄅᆡ와 곳간에 ᄡᅳᄂᆞᆫ 모든 일)라. 둘은 오직 db로ᄡᅥ ᄆᆞᆯᄒᆞᄂᆞ니라.

## ᄆᆞᆫᄃᆞᄂᆞᆫ 이ᄅᆞᆯ 위ᄒᆞ여

```sh
python3 -m venv .venv && .venv/bin/pip install -e '.[dev]'
.venv/bin/pytest              # YouTube에ᄂᆞᆫ 결단코 가지 아니ᄒᆞᄂᆞ니, 시험은 tests/fake_ytdlp.py를 ᄡᅳᄂᆞ니라
.venv/bin/ruff check src tests && .venv/bin/ruff format src tests
```

거즛 yt-dlp로 제 긔계에셔 돌니려면 `config.dev.toml`(git이 모ᄅᆞᄂᆞᆫ 파일)을 ᄆᆞᆫᄃᆞᆯ라:

```toml
[paths]
origin = "./.dev"       # 샹ᄃᆡ 경로ᄂᆞᆫ 이 파일이 잇ᄂᆞᆫ 곳을 긔쥰ᄒᆞᄂᆞ니라
pool = "./pool"
[server]
port = 8471
serve_media = true      # ᄆᆞᆫᄃᆞᆯ ᄯᆡ에만: FastAPI가 /media와 frontend를 내여 주ᄂᆞ니라
serve_static = true
[pool]
max_bytes = 30_000_000  # 아조 쟉게 ᄒᆞ야 ᄇᆞ리기가 졍녕 닐어나게 ᄒᆞ라
min_free_bytes = 0
[ytdlp]
binary = "tests/fake_ytdlp.py"
sleep_requests = 0.0
sleep_interval = 0
max_sleep_interval = 0
[discovery]
rss_url_template = ""   # RSS 업시 (거즛) ᄎᆡ널 목록을 ᄡᅳ라
```

```sh
export THYTUBE_CONFIG=config.dev.toml
.venv/bin/thytube serve &      # http://localhost:8471/
.venv/bin/thytube worker &
```

`FAKE_YTDLP_MODE=botcheck`(혹 `403`, `429`, `private` …)로 일군을 시작ᄒᆞ면 형셰ᄅᆞᆯ ᄉᆞᆯ피ᄂᆞᆫ
장치가 제 구실ᄒᆞᄂᆞᆫ 양을 보리라. `tests/fake_ytdlp.py` 머리에 모든 mode가 젹혓ᄂᆞ니라.

frontendᄂᆞᆫ build ᄒᆞᄂᆞᆫ 단계가 업ᄂᆞ니, 다만 ES module과 vendored Preact + htm(`web/vendor/`)ᄲᅮᆫ이니라.

**집의 법도:** ThyTubeᄂᆞᆫ 그 쥬인을 ᄒᆞᆫ 사ᄅᆞᆷ으로 부ᄅᆞᄂᆞ니라. 영어 글월은 *thou / thee / thy /
thine*이라 ᄒᆞ고 결단코 *you / your*라 아니ᄒᆞ며, 됴션말 글월은 근ᄃᆡ 국어로 *그ᄃᆡ*라 부ᄅᆞᄂᆞ니라.
화면의 말은 다 `web/lang/<code>.json`에 잇고, 코드와 주셕은 녜ᄉᆞ 영어로 두ᄂᆞ니라.

## 셔버에 노키

그ᄃᆡ 셔버에만 ᄒᆡ당ᄒᆞᆫ 거슨 다 `config.toml`과 `deploy/deploy.env`에 잇ᄂᆞ니, 둘 다 git이
모ᄅᆞᄂᆞᆫ 파일이니라. 모든 열쇠ᄂᆞᆫ `config.example.toml`에 풀어 젹혓ᄂᆞ니, 졀ᄃᆡ 경로ᄅᆞᆯ ᄡᅳ라.

1. **app 사용쟈로, 그ᄃᆡ의 ᄆᆞᆫᄃᆞᄂᆞᆫ 긔계에셔**: `deploy/deploy.env.example`을 `deploy/deploy.env`로
   벗기고 ᄎᆡ와 `deploy/deploy.sh`ᄅᆞᆯ 돌니라. 코드ᄅᆞᆯ 옴기고, venv를 지으며 (혹 ᄃᆞ시 지으며),
   ᄎᆞᆺ 번에ᄂᆞᆫ yt-dlpᄅᆞᆯ 셜티ᄒᆞ고, db의 틀을 새로 ᄒᆞ고, `thytube doctor`ᄅᆞᆯ 돌니ᄂᆞ니라. 맨 처엄
   돌닐 ᄯᆡ에ᄂᆞᆫ 본으로브터 `config.toml`을 ᄡᅳ고 그치ᄂᆞ니, 그ᄃᆡ로 ᄒᆞ여곰 고치게 ᄒᆞ려 ᄒᆞᆷ이라.
2. **root로, ᄒᆞᆫ 번만**:
   - web 셔버: Apache 본 둘 듕 ᄒᆞ나ᄅᆞᆯ ᄎᆡ와 `/etc/apache2/vhosts.d/`에 벗기라.
     - `deploy/apache/thytube-port.conf`ᄂᆞᆫ ThyTube에 LAN port ᄒᆞ나ᄅᆞᆯ ᄯᆞ로 주ᄂᆞ니 DNS가
       ᄡᅳᆯᄃᆡ업ᄂᆞ니라. 그 port를 firewall에셔 LAN zone에만 열라.
     - `deploy/apache/thytube-hostname.conf`ᄂᆞᆫ port 80의 일홈으로 ᄀᆞᆯᄒᆡᄂᆞᆫ vhost니, 모든 긔계에
       local DNS나 hosts 항목이 이셔야 ᄒᆞᄂᆞ니라.

     둘 다 ᄉᆞᄉᆞ 주소 범위(`Require ip`)만 드리고, `/media/`ᄅᆞᆯ 곳간에셔 바로 Range와 immutable
     cache header로 내여 주며, `/api/`ᄂᆞᆫ uvicorn으로 넘기ᄂᆞ니라.
   - process: `deploy/systemd/*.service`의 `@ORIGIN@`을 ᄎᆡ와 `/etc/systemd/system/`에 벗기고
     `systemctl enable --now thytube-web thytube-worker`ᄅᆞᆯ 돌니라. systemd를 ᄡᅳ고져 아니ᄒᆞ거든
     `deploy/crontab.txt`의 `@reboot`와 `*/5` 줄이 root 업시도 둘ᄋᆞᆯ 니어 돌니ᄂᆞ니라. 둘 듕
     ᄒᆞ나만 ᄡᅳ고, 결단코 둘을 ᄒᆞᆷᄭᅴ ᄡᅳ지 말라.
3. **app 사용쟈의 crontab**: ᄆᆡ일 돌닐 `thytube update-ytdlp`ᄅᆞᆯ 위ᄒᆞ여 `deploy/crontab.txt`를
   셜티ᄒᆞ라.

web process를 ᄃᆞ시 시작ᄒᆞ여도 ᄂᆞ려밧기ᄂᆞᆫ 결코 ᄭᅳᆫ기지 아니ᄒᆞᄂᆞ니라. 일군은 SIGTERM을 밧으면
졈잔히 믈너나ᄂᆞ니, 시방 ᄂᆞ려밧던 거ᄉᆞᆯ 그만두고 제 자리ᄅᆞᆯ 치우고 그 영샹을 ᄎᆞ례에 도로 두ᄂᆞ니라.

### <a id="https"></a>셜티ᄒᆞᄂᆞᆫ app을 위ᄒᆞᆫ HTTPS

browser가 *앱 설치*(Android와 desktop에셔)ᄅᆞᆯ 권ᄒᆞ고 offline에셔 app을 여ᄂᆞᆫ 거슨 HTTPS로
ᄎᆞ자올 ᄯᆡᄲᅮᆫ이니라. 그저 HTTP라도 그 밧긔 일은 다 되고, iOS의 *홈 화면에 추가*도 온 화면 app을
그ᄃᆡ의게 주ᄂᆞ니라.

LAN에셔 HTTPS를 ᄡᅳ려면 [mkcert](https://github.com/FiloSottile/mkcert)로 그ᄃᆡ만의 쟈근 CA를
셰우라:

```sh
mkcert -install                        # 그ᄃᆡ의 local CA를 셰우ᄂᆞ니라
mkcert <server-ip> <server-hostname>   # 셔버의 인증셔ᄅᆞᆯ 내여 주ᄂᆞ니라
```

그 후에 root로 인증셔와 열쇠ᄅᆞᆯ 셔버에 옴기고, `mod_ssl`을 켜고, vhost의 `SSL…` 줄의 주셕을
프러라 (혹 hostname vhost를 `*:443`으로 벗기라). ᄆᆞᄌᆞ막으로 긔계마다 그ᄃᆡ의 CA(`rootCA.pem`,
`mkcert -CAROOT`로 ᄎᆞᆺᄂᆞ니라)ᄅᆞᆯ 밋게 ᄒᆞ라:

- **iPhone/iPad**: 파일을 긔계에 보내여 profile을 셜티ᄒᆞ고, 설정 › 일반 › 정보 › 인증서 신뢰 설정에셔
  켜라.
- **Android**: 설정 › 보안 › 암호화 및 사용자 인증 정보 › 인증서 설치 › CA 인증서.

### 명녕

```
thytube serve | worker | migrate | update-ytdlp [--force] | rollback-ytdlp | probe | reconcile | doctor
```

## YouTube가 그ᄃᆡᄅᆞᆯ 막을 ᄯᆡ에

쇼식 화면이 시방 형셰ᄅᆞᆯ 쉬온 말로 풀어 니ᄅᆞᄂᆞ니라. 그ᄃᆡ가 ᄒᆞᆯ 수 잇ᄂᆞᆫ 일은 대강 이 ᄎᆞ례니라:

1. **기ᄃᆞ리라.** canary 시험은 15분브터 6시간ᄭᆞ지 ᄎᆞᄎᆞ 사이ᄅᆞᆯ 늘이고, 통과ᄒᆞᄂᆞᆫ 즉시 ᄎᆞ례가
   ᄃᆞ시 움ᄌᆞᆨ이ᄂᆞ니라.
2. **고치라.** 쇼식 화면의 *이졔 yt-dlp 고치기*ᄅᆞᆯ 누르거나 `ytdlp.channel = "nightly"`로 두라.
   nightly 판이 YouTube 탓으로 ᄭᆡ진 거ᄉᆞᆯ 더 ᄲᆞᆯ니 깁ᄂᆞᆫ 일이 만ᄒᆞ니라.
3. **ᄂᆞ즉이 ᄒᆞ라.** `sleep_requests`, `sleep_interval`, `max_sleep_interval`을 올니라.
4. **token을 가져오라.** `ytdlp.extra_pip_packages`로 PO-token provider plugin을 yt-dlp venv에
   셜티ᄒᆞ라.
5. **ᄆᆞᄌᆞ막 슈니, 본ᄃᆡᄂᆞᆫ ᄭᅥ 두엇ᄂᆞ니라.** `ytdlp.cookies`에 *ᄇᆞ려도 됴ᄒᆞᆫ* Google 계뎡에셔
   내여 온 `cookies.txt`ᄅᆞᆯ 두라. Google이 그 cookie의 쥬인 계뎡을 표ᄒᆞ거나 막을 수
   잇ᄂᆞ니라. **그ᄃᆡ 제 계뎡은 결단코, 결단코 ᄡᅳ지 말라.**

## 젹어 둘 것

- 영샹은 H.264/AAC MP4(본ᄃᆡᄂᆞᆫ ≤ 1080p, `faststart`)로 간직ᄒᆞᄂᆞ니, iOS에셔 transcode 업시
  ᄌᆡᄉᆡᆼᄒᆞᄂᆞ니라. ᄃᆞᄅᆞᆫ codec만 잇거든 영샹은 그ᄃᆡ로 간직ᄒᆞ되 경계ᄒᆞᄂᆞᆫ 패ᄅᆞᆯ ᄎᆞᄂᆞ니라.
- ᄌᆞ막은 ᄯᆞ로 ᄒᆞᄂᆞᆫ 단계에셔 가져오ᄂᆞ니, 그릇되여도 영샹은 샹ᄒᆞ지 아니ᄒᆞᄂᆞ니라 (YouTube가 ᄌᆞ막
  쳥에 429로 ᄃᆡ답ᄒᆞᄂᆞᆫ 일이 흔ᄒᆞ니라). ᄌᆞ막은 ᄭᆡᄭᅳᆺ이 시서 ThyTube 제 덥개에 뵈고, iPhone의 온
  화면 ᄌᆡᄉᆡᆼ긔ᄅᆞᆯ 위ᄒᆞ여 native track도 ᄒᆞᆷᄭᅴ ᄃᆞᄂᆞ니라. 본ᄃᆡᄂᆞᆫ ᄎᆞᆷ ᄌᆞ막과, 영샹 제 말의 긔계
  ᄌᆞ막만 가져오고, 긔계 번역은 가져오지 아니ᄒᆞᄂᆞ니라.
- ᄌᆞ리ᄅᆞᆯ 내려고 ᄇᆞ린 영샹은 구독이 결단코 ᄃᆞ시 ᄂᆞ려밧지 아니ᄒᆞᄂᆞ니, 오직 그ᄃᆡ가 "ᄃᆞ시
  간직ᄒᆞ기"로 도로 가져올 수 잇ᄂᆞ니라.

## 엇지ᄒᆞ야 "Thy"뇨?

이ᄂᆞᆫ **그ᄃᆡ의** 거신 젼ᄎᆞ니라. 그ᄃᆡ의 셔버, 그ᄃᆡ의 디스크, 그ᄃᆡ의 구독, 그ᄃᆡ의 일이니라. 그ᄃᆡ가
다음에 므어ᄉᆞᆯ 볼지ᄂᆞᆫ ᄂᆞᆷ의 algorithm이 뎡ᄒᆞ지 못ᄒᆞᄂᆞ니라. 그ᄃᆡᄂᆞᆫ ᄌᆞ최ᄅᆞᆯ 밟히지 아니ᄒᆞ리라.
